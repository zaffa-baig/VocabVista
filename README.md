🧠 # Vocab Challenge Game
A daily vocabulary learning game designed to help users build a consistent habit of learning new words and track their progress through streaks. Challenge yourself every day to improve your streak!

✨# Features

-   Daily Challenge: A new vocabulary game starts every 24 hours.
-   Streak Tracking: Improve and maintain your learning streak with successful
    daily completion.
-   Habit Formation: The 24-hour countdown encourages daily participation and consistency.
-   Streak Reset: If the challenge is not completed within the 24-hour window, the streak
    resets, motivating users to stay on track.
-   Responsive Design: Accessible and playable across different devices.

🛠️ # Tech Stack

This project is built using modern front-end technologies and architectural patterns.

-   Front-end Framework: React
-   Styling: Fanta CSS
-   State Management: Built-in React State Management (using useState).
-   Core React Concepts:
    _ React Event Handlers: For managing user interactions (clicks, input changes, etc.).
    _ React Hooks: Utilized for managing component state and side effects (e.g., useState, useEffect). \* Component Splitting: The UI is organized into reusable and modular components for maintainability and  
     scalability.

💻 Getting Started

**Prerequisites**

You will need the following installed on your system:
Node.js (LTS version recommended)
npm or yarn

**Installation**

## Clone the repository:

Bash
git clone https://github.com/zaffa-baig/VocabVista
cd VocabVista

## Install dependencies:

Bash
npm install

# OR

yarn install

##

Run the application locally:
Bash
npm start

# OR

yarn start

The application will typically open in your browser at http://localhost:5173/
